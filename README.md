## Documentación

La documentación de cada módulo se mantiene en su propio `README.md`. Las carpetas `examples` contienen ejemplos de uso y pueden incluir documentación específica.

Para regenerar la documentación de un módulo desde su carpeta:

```powershell
terraform-docs markdown table --output-file README.md --output-mode inject .
```

# Módulo Terraform: Resource Group

Despliega un `Resource Group` reutilizable para el catálogo de IA.

## Recursos Terraform

- `azurerm_resource_group`

## Entradas relevantes

- `resource_group_name`
- `location`
- `tags`

## Outputs principales

- `id`
- `name`
- `location`

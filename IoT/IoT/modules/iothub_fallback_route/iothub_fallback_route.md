# Módulo Terraform: IoT Hub Fallback Route

Despliega una `Fallback Route` sobre un `IoT Hub`.

## Recursos Terraform

- `azurerm_iothub_fallback_route`

## Restricciones y notas

- usa este recurso en lugar del bloque inline `fallback_route` del `azurerm_iothub`

## Outputs principales

- `id`

- Terraform Registry: `azurerm_iothub_fallback_route`

# Módulo Terraform: Virtual Desktop Workspace Application Group Association

Asocia un `Application Group` a un `Workspace` de Azure Virtual Desktop.

## Recursos Terraform

- `azurerm_virtual_desktop_workspace_application_group_association`

## Cuándo usarlo

- cuando necesitas publicar un desktop o un conjunto de RemoteApps dentro de un workspace

## Entradas relevantes

- `workspace_id`
- `application_group_id`

## Outputs principales

- `id`
